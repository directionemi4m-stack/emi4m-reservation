# Icônes PWA — en attente

Déposer le logo source (`logo-emi4m.jpg` ou `.png`) à la racine de `public/`, puis générer ici :

- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- `icon-maskable-512.png` (512×512, logo centré avec ~20% de marge de sécurité sur les bords, fond plein — requis par le format maskable)

Référencées par `src/app/manifest.ts` et `src/app/layout.tsx`.
